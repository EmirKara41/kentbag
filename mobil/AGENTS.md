# KentYanımda Android

This is a fresh Android citizen app built with React, TypeScript, Vite and Capacitor.
The previous Expo prototype is archived in ../arsiv and must not be reused as this app's UI.

- Deliver the installed app experience: embedded screens, native back, keyboard and safe areas, native camera/GPS, real server receipts.
- Never depend on Expo Go, Metro, a running computer, or an externally hosted UI for the installed app.
- Use current installed Capacitor version documentation and typings before calling plugin APIs.
- Never show fabricated municipal action or demo reports as the citizen's records.
- Keep server credentials out of mobile builds. Unconfigured service and network errors must be clear and preserve drafts.
- Run typecheck, lint, relevant tests and APK verification before declaring the app ready.
- Do not alter the reference Pusula project in Desktop/WU.
